# 手机 App 体验

- 手机使用占满视口的 App 外壳，顶部标题和底部四个导航保持固定，中间内容独立滚动。适配顶部状态栏、底部手势条和横屏触屏设备。
- 四个导航保持相同尺寸，当前页高亮，切换时分别记住各页滚动位置。底部为内容和提示留出安全空间，避免最后一项被导航遮住。
- 手机端去掉网页面包屑、页尾宣传文字和可见滚动条；桌面继续使用侧栏。
- 固定页面根容器的宽度和位置，内容区只允许纵向平移，禁止滚动边界回弹与横向溢出；保留双指缩放。取消快速输入框的 117% 宽度缩放，所有手机表单输入保持至少 16px 字号，避免 iOS 聚焦时自动放大后产生横向位移。
- 生产响应设置 `script-src 'self'`、`frame-src 'none'` 等 CSP，只允许运行本站脚本并禁止嵌入式浮层，避免 Powered by Netlify 盖住导航。当前应用不使用嵌入页面或内联脚本，样式、本地备份与通知 Service Worker 不受影响。Netlify 官方明确说明省略 unsafe-inline 的 script-src 可阻止其浮层显示，见 https://docs.netlify.com/manage/projects/powered-by-netlify-badge/ 。
- 新图标为粉红色像素太阳；提供版本化的 iPhone 180px、Android 192/512px 和 maskable 图标。保留原来的应用 ID、起始地址和本地数据键，图标更新不创建新的存储来源。
- iPhone 使用 Safari → 分享 → 添加到主屏幕，保持「作为网页 App 打开」（如出现）开启，然后从主屏幕启动。Android 使用安装入口。普通浏览器标签页仍会显示浏览器自己的工具栏，网站不能将其强行隐藏。
- 桌面图标由系统缓存；旧图标未刷新时可重新添加到主屏幕。不要为换图标清除浏览器或 App 数据；操作已安装的应用前先在「我的」导出备份。

当前生产网址：https://fancy-marshmallow-6241c4.netlify.app/

验证：TypeScript 与生产构建通过，39 项现有业务测试通过。浏览器检查覆盖 390×844、320×568；确认内容滚动时导航位置不变、没有横向溢出、点击区域至少 57px 高、切换后滚动位置恢复。iPhone 的真实刘海、键盘及主屏幕图标缓存仍需在实机检查。
