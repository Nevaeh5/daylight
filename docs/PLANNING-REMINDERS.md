# 一句话日程、随心记与后台提醒

## 使用

- 一句话入口支持今天/明天/后天、周几/下周/下下周、数字年月日，以及上午/下午/晚上、中文数字点钟、半点和分钟。识别后必须核对保存；没有日期按今天预填，没有时间或上午/下午不明确会给出提示。不是完整自然语言模型，重复日程和复杂表达请手动核对。
- Top 3 和当日安排继续互斥。随心记是独立的无日期待办，在今天页一直保留，不计入当日进度、Top 3、日历和提醒。支持新增、完成、删除，包含在 JSON 备份中。旧版备份仍可读取。
- 有时间的日程默认勾选提前 15 分钟提醒，可关闭。旧日程不自动开启，编辑保存后按勾选状态设置。
- 在正式网站开启后台提醒。iPhone 需要 iOS 16.4+，Safari 分享 → 添加到主屏幕 → 从主屏幕打开 → 开启后台提醒 → 允许通知。
- 点击发送测试通知确认系统允许通知。再新增约 17 分钟后的日程，确认同步成功后关闭应用并锁屏，在开始前约 15 分钟检查通知。

## 后台

采用 Netlify Functions + Blobs + Web Push。VAPID 密钥在服务端首次调用时生成，原子写入私有 Blobs，跨部署保留；仅公钥对外提供，无需将私钥提交到仓库或手动配置。设备在本机生成 256 位随机凭证，服务端使用其 SHA256 命名设备记录，接口不提供设备枚举或私有数据读取。

开启后只上传需要提醒的未完成日程的 ID、标题、开始时间以及通知订阅。随心记、日记、任务备注不上传；这不是任务账户或跨设备同步。完成、删除、关掉提醒或恢复备份后会替换该设备的后台队列。未联网或同步失败会显示错误，需要联网重试；退出前请确认同步完成。关闭后台提醒会删除后台设备队列。清除浏览器数据前应先关闭后台提醒，否则旧提醒可能继续发送。

`send-reminders` 每分钟在生产部署运行，时间点以设备本地时间转换成 UTC 时间戳，跨午夜可用。到期前 15 分钟进入推送窗口；距开始不足 15 分钟的新增安排会尽快发送。已经开始的日程不会补发。单个任务和开始时间去重，临时失败下次重试，404/410 失效订阅会移除。发送服务只允许已知 HTTPS 浏览器推送域名，避免任意地址请求。

Netlify 的计划任务只在 Published 的生产部署自动执行。网络、后台调度、推送服务、专注模式和设备系统可能导致延迟，不能保证精确到秒。定时扫描和存储计入现有 Netlify 用量。服务器发送成功代表推送服务接收，不能证明特定 iPhone 已弹出通知。

## 验证

自动测试覆盖中文日期时间、跨年、无效/歧义提示、随心记隔离、备份兼容、最小提醒数据、取消与完成、服务端凭证、来源与推送地址校验、15 分钟窗口、去重、临时失败重试与订阅过期处理。生产构建包括 `push-events.js` 和导入该文件的 Service Worker。

浏览器检查已确认中文预填、默认提醒勾选、保存至指定日期、随心记跨日保留且不进入日程。锁屏送达需要在目标 iPhone 上完成授权与实际定时测试，未将模拟测试当作实机验收。
