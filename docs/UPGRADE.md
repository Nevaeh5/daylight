# 陪伴版升级 · 2026-11-01

本文件描述本次新增要求的最终状态，优先于初版 ARCHITECTURE.md、VALIDATION.md 中尚未实现的描述。

## 结构和行为

1. `splitDayTasks` 在领域层给出互斥的 focus/schedule：首页 Top 3 只显示 focus，今日安排只显示 schedule；进度仍统计两类全部任务。月历当日清单也按两组显示。用户在编辑框勾选重点即移动分组，不复制任务。
2. `pixel-upgrade.css` 在原布局之上提供暖麦黄/蜂蜜棕色系、像素硬边框与阶梯阴影。SVG 房间、轻量 steps 动画保留，不引入游戏引擎。月历和日记拥有独立 React 模块。
3. 宠物每日一句采用本地日期确定的语录，首次显示每天不同的句子；点击小狗循环切换。摸头、喂食、伸懒腰返回反馈，喂食与活动每天各加一次陪伴值，上限 5。重复互动不惩罚、不刷数值。完成任务和三件重点会触发首页小光反馈。日记收好后给出感谢文案。宠物值随 JSON 备份导出。
4. 主月历使用周一开头、42 格稳定布局。日期只要有任务即显示星号，重点金色、已完成划线，每格最多两项和剩余数量。手机格内优先显示标题，完整时间与备注通过当日清单/编辑查看。跨月导航和点击日期使用本地日期计算。
5. 感恩日记无时间门槛；三个提示问题自由填写，写入即本地保存，每天唯一、历史可修改。跨标签更新会同步到当前编辑器。提醒默认 22:00，仅应用打开时检查，已写当天日记则不提醒，可关闭或当日跳过，不申请系统通知权限。

## 数据兼容

继续使用原先版本号 1，增加可选字段 journals、pet、journalReminderEnabled、reminderDismissedOn，旧数据不强制迁移。journals 按日期唯一，答案长度和日期均校验。备份恢复同时替换所有实体，提示明确包括日记和陪伴信息。数据仍是本机浏览器存储，不宣称跨设备同步。
