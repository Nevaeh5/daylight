# 简洁模块调整

- 今天：Top 3 → 带魔法棒的空白一句话输入框 → 今日安排 → 随心记。输入后继续展示日期、时间识别结果，核对保存；当前识别仍使用本地中文规则，没有向 AI 服务发送内容。
- 日历：按日期查看与管理当日事项。
- 日记：单个自由输入框，提交一条后清空，可继续提交。已提交内容按当天逐条展示，支持编辑、删除，按日期查看。去掉三类提示、场景横幅和美好足迹。
- 我的：仅保留通知设置、日记晚安邀请开关、备份恢复、安装说明；去掉成长计划与内容数量统计。后台推送组件在其他页隐藏但保持运行，确保日程更改仍能同步提醒。

新记录保存在版本 1 备份的可选 journalEntries 字段中，每条记录独立 ID、日期、正文及时间戳。旧 journals 三栏结构继续兼容，并在页面按非空栏逐条展示；新增日记不会覆盖旧数据。新记录和旧记录均可编辑、删除、导出恢复，写过当天的新记录后不再弹出晚安邀请。

验证：42 项自动测试通过，生产构建通过。手机浏览器验证今天页的入口顺序与空白状态、日记连续提交两条、我的设置归属及无横向溢出。
