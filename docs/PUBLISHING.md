## 一次授权，后续直接发布

完成 Codex 的 GitHub 连接并允许访问 daylight 仓库后，后续可由 Codex 执行检查、提交和推送。用户不需要安装 GitHub Desktop，也不必再打包或手动上传源代码。连接完成必须验证实际写入权限，不能把仓库可公开读取当成能推送。

生产分支为 main。推送前 fetch 检查远端进度，存在远端新改动则先合并，不使用 force push。通过构建与适用测试后再提交和推送。Netlify 接到 main 的新提交会构建并更新原项目，发布结束需检查实际部署结果。

GitHub 连接尚未确认时，只能报告本地完成，不能报告线上更新。不要要求用户把 token 或密码发进聊天，也不要把它们写进源码、日志或发布包。
