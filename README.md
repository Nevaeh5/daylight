# Daylight · 暖色像素陪伴日程管家

React + TypeScript + Vite PWA，本地存储版。小狗「小光」陪你规划日程、收集每天的美好。

## 当前可用

- 任务 CRUD、完成状态、可选时间/优先级/备注、历史日期。
- 一句话添加日程：识别常见中文日期和时间，核对后保存；有时间的日程默认提前 15 分钟提醒。
- 独立随心记：跨日保存无具体时间的长期待办，不进入日历、Top 3、当日安排或进度统计。
- 可选 Web Push 后台提醒：正式 Netlify 部署后开启，支持关闭应用后推送；iPhone 需添加到主屏幕并授权通知。提醒开启会把需要提醒的日程标题、时间与订阅同步到后台，随心记和日记不上传。
- Top 3 和其他安排互斥：设为重点后从其他安排移出，取消重点后回到其他安排；每天最多三件重点，可排序。
- 主月历：日期星标、事项标题概览、重点金色标记、跨月查看和当日完整清单。
- 小光每日一句，点击切换鼓励语；摸头、喂饼干、伸懒腰，陪伴值轻量增长并本地保存；同日同类互动不重复加值。
- 感恩日记自由输入、逐条提交，同一天可记录多条，支持编辑与删除；旧版三栏内容按条保留。22:00 应用内晚安邀请可在「我的」关闭。
- JSON 导入导出含任务、日记、陪伴状态及提醒偏好；兼容最初只有 tasks 的 v1 备份。恢复会替换本机所有这些数据。
- 暖色像素框、SVG 小屋、CSS 轻动画、移动端安全区域与减少动态效果支持。

## 启动和构建

双击项目中的「启动Daylight.cmd」启动，访问 http://localhost:5173 。双击「生成部署文件.cmd」构建可上传的 dist。

有 pnpm 的环境也可运行：

~~~powershell
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
~~~

当前 Codex 环境没有全局 npm，两个 cmd 启动器会使用内置 pnpm。需要 Node 22.12+ 或 24。

## 部署和 iPhone 桌面安装

安装步骤见 [部署到iPhone](docs/部署到iPhone.md)。需要后台提醒时必须通过 GitHub → Netlify 部署完整项目（含 netlify/functions），只上传 dist 无法提供后台提醒。详细使用与验收见 [日程与后台提醒](docs/PLANNING-REMINDERS.md)。

不同设备、端口和域名的记录各自保存，本地版没有云同步；恢复备份可迁移数据。清除网站数据可能导致记录丢失。开发服务器不注册离线 Service Worker；生产构建会生成缓存文件，但 iPhone 真机离线启动仍需部署后验收。

## 提醒边界与后续能力

22:00 日记邀请仍为应用内提醒；日程的提前 15 分钟提醒通过独立的 Netlify 计划任务和 Web Push 提供，不依赖页面计时器。网络、系统通知与专注模式可能影响送达。中文识别采用本地规则，复杂或重复表达请手动核对。账户/云同步、重复规则、完整日周时间轴与日历双向同步仍待后续接入。锁屏提醒需要在目标手机完成实际验收。

架构计划见 docs/ARCHITECTURE.md，最新升级记录与验收结果见 docs/UPGRADE.md。
